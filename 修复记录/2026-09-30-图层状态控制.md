# 2026-09-30 图层状态控制（关闭/冻结/锁定）

## 背景

图层是 CAD 最核心的组织概念，但此前 `dxf_layers` 只能管颜色/线型，
不能控制图层可见性。用户确认需要"图层开关/冻结/锁定"。

## 变更

1. **`dxf_layers` 增加三个可选布尔字段**（每个图层 spec）：
   - `on`：`false` = 关闭图层（不显示不打印）
   - `frozen`：`true` = 冻结（不显示，且不参与重生成/选择）
   - `locked`：`true` = 锁定（显示但不能编辑）
2. **`dxf_read` 图层列表升级**：从纯名字列表变为对象，含
   `name / on / frozen / locked / color`（color 用 `get_color()` 取绝对值，
   规避 off 图层的负色值）。
3. 版本号 0.4.0 → 0.5.0。

## ezdxf 踩坑（关键发现）

1. **off 不在 flags 位里，而在颜色符号里**：ezdxf 的 `is_off()` 判断
   `dxf.color < 0`，`off()` 就是 `color = -abs(color)`。frozen/locked 才是
   group 70 的位（FROZEN=1, LOCK=4）。
   → 所以 `on/off` 必须放在 `color` 赋值之后，否则 off 会把刚设的颜色再取负。
2. **渲染器行为验证**（与 AutoCAD 语义一致）：
   - off / frozen 的图层实体在 PNG 预览中被跳过
   - locked 只影响编辑、不影响显示（预览仍画出）
3. **`*D` 标注几何块预览颜色问题**（演示时发现）：
   - 标注的 `*D` 几何块实体默认 layer=0、color=0(ByBlock)，
     ezdxf 预览按块所在图层（0）解析 → 放在彩色标注层的标注预览仍显示白色
   - 规避：给 `*D` 块内实体设显式颜色，预览即跟随；AutoCAD 按 ByLayer
     渲染，终显正确（已写入 README 已知限制）
   - 本记录对应的桌面演示文件（正方形20cm.dxf）的 `*D` 块实体已显式设为红色

## 验证

- 单元：三状态设置 + dxf_read 新格式 + 保存重载往返（off/frozen/locked 均保持）
- 渲染：off/frozen 图层实体在预览中消失，locked 不影响显示
- 桌面演示：`/Users/xianghaojing/Desktop/正方形20cm.dxf` 建
